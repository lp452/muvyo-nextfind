# NextFind 影巢

把 Muvyo 的资源搜索接到你自己部署的 **NextFind** 上：影巢（HDHive）和频道资源都由 NextFind 代为访问与兑换，插件只跟你局域网里的 NextFind 说话。

## 为什么需要它

影巢现在的域名 `re0.me` 全站开了 Cloudflare 托管挑战，任何不是浏览器的客户端（包括直接在容器里抓网页的插件）访问任何路径都是 `403 Cf-Mitigated: challenge`。NextFind 用的是影巢的接口 Key，能正常读资源、签到、兑换积分，所以把这件事交给它最稳。

## 配置

| 项 | 说明 |
|---|---|
| NextFind 服务地址 | 例如 `http://192.168.1.21:8092` |
| NextFind 账号 / 密码 | NextFind 后台的登录账号，插件用来自动登录，会话存在插件自己的存储里 |
| 最多返回条数 | 默认 60，上限 200 |
| 只返回 115 资源 | 打开后丢掉电驴等其它类型 |
| 隐藏需要积分的资源 | 打开后只给免费 / 已解锁的，绝不会产生积分消耗 |

## 能力

- **资源搜索**：出现在资源搜索、订阅自动搜索、机器人搜索里。按 TMDB 编号直接查；只有关键词时先用 NextFind 的搜索落到 TMDB 编号再查。
- **按需换取链接**：不在搜索时扣积分。只有你点「获取链接」，或订阅里明确允许，才会调用 NextFind 解锁。已解锁的条目按 0 积分处理。
- **影巢每日签到**：定时任务，默认每天一次，结果会带当前积分。
- **账号信息**：设置页顶部显示影巢账号、积分、今日是否已签到、授权到期日。

## 说明

- 搜索结果的链接来自 NextFind 的解析：115 分享（自动补 `?password=`）、电驴直链、磁力。
- 需要积分的条目只给令牌，积分由 NextFind 扣，Muvyo 这边标 `points`，订阅自动获取受 Muvyo 自己的积分上限约束。
- NextFind 有兑换冷却时会直接返回「冷却中，约 N 秒后再试」，不会反复重试。
